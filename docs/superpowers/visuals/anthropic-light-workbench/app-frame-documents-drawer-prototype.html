RAG Retrieval Best Practices

This page represents the full preview route for a selected document. The frontend only renders content returned by the preview API; it does not guess links from physical file paths.

1. Retrieval Flow

Documents are uploaded first, then added to RAG from the document list. When indexing completes, references from chat can open this same safe preview route.

  • Markdown and text render as readable content.
  • Converted DOCX content appears as Markdown when available.
  • Missing preview content shows an explicit empty state.

2. Contract Boundary

The UI calls GET /api/document-preview/{id}/content and renders the returned fileName, contentType, and content.
