Clear plan

清理动作必须显示影响面，避免把“维护按钮”做成事故按钮。

Clear stale query cache

只删除旧 workspace revision 的 query answer，不动 keywords / extract / summary。

Clear unused summary cache

删除 30 天未访问 summary entries；下次 merge 描述时会重新生成。

Clear all LLM cache

会降低重复查询和重复索引效率。必须二次确认，并展示当前 saved-call 损失。
